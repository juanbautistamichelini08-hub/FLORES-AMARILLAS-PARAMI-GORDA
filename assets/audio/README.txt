CARPETA DE MÚSICA
===================

Para personalizar la música de fondo de esta experiencia romántica:

1. Elige tu canción favorita (en formato .mp3).
2. Nómbrala exactamente como:
   music.mp3
3. Guárdala dentro de esta carpeta (assets/audio/music.mp3).

¡Listo! Al cargar o interactuar con la página, el reproductor detectará automáticamente tu archivo MP3 y comenzará a sonar suavemente.

Nota: Si no colocas ningún archivo MP3, la página cuenta con un sintetizador ambiental romántico integrado (vía Web Audio API) que produce una melodía suave de piano y campanillas para que nunca se quede en silencio.
